# Autonomous Military Robots Simulation

## 📌 О проекте

Проект представляет собой симуляцию автономного наземного робота, 
который самостоятельно перемещается по заданной карте.

Робот использует данные LiDAR для обнаружения препятствий, построения 
карты окружающей среды и навигации по заданному маршруту.

Проект предназначен для демонстрации принципов автономной навигации 
наземных роботизированных систем.

---

## 🎯 Основные задачи

- автономное перемещение робота;
- построение и использование карты местности;
- обнаружение препятствий с помощью LiDAR;
- планирование маршрута;
- обход препятствий;
- моделирование движения робота;
- визуализация процесса навигации.

---

## 🧠 Используемые технологии

- Python 3
- NumPy
- Matplotlib
- LiDAR simulation
- Path Planning
- Autonomous Navigation
- 2D Robot Simulation
